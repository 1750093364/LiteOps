# LiteOps 公网 Demo 部署操作说明

面向新手的 3 步部署流程，目标服务器：阿里云 ECS Ubuntu 22.04，公网 IP `39.106.48.34`，安全组已放行 22 与 80 端口。

---

## 第 1 步：生成服务器部署包（在你自己的 Windows 电脑上）

在项目根目录执行：

```bat
python scripts\make_dist.py --server
```

执行完毕会在项目下生成 `dist\LiteOps_server.zip`（含 `app/`、`web/`、`scripts/`、`examples/`、`docs/PRD.md`、`requirements.txt`、`deploy/`、`README.md`）。

---

## 第 2 步：上传并解压到服务器

在**项目根目录**打开 PowerShell，依次执行（把 `<你的密码>` 换成服务器 root 密码，输入时不显示）：

```powershell
scp dist\LiteOps_server.zip root@39.106.48.34:/root/upload/
ssh root@39.106.48.34 "mkdir -p /root/upload/liteops && cd /root/upload && unzip -o LiteOps_server.zip -d liteops"
```

> 如果 `unzip` 未安装，先执行 `apt-get install -y unzip`。

---

## 第 3 步：运行部署脚本

```powershell
ssh root@39.106.48.34 "sudo bash /root/upload/liteops/deploy/deploy_server.sh"
```

脚本会交互式询问以下问题，按提示回答即可：

| 问题 | 默认值 | 说明 |
|---|---|---|
| BasicAuth 用户名 | `demo` | 访问网站时输入的用户名，直接回车用默认 |
| BasicAuth 密码 | （必填） | 访问网站时输入的密码，需输入两次校验 |
| DeepSeek API Key | （可空） | 直接回车则 AI 功能不可用，其余功能正常；填入 sk- 开头的 Key 则启用 |
| AI Base URL | `https://api.deepseek.com/v1` | 直接回车用默认 |
| AI 模型名 | `deepseek-chat` | 直接回车用默认 |

脚本执行完毕会自动打印自检结果：`systemctl is-active liteops` 应为 `active`，`curl -I 127.0.0.1:8000` 返回 HTTP 200，`curl -I http://127.0.0.1` 返回 HTTP 401（BasicAuth 生效）。

---

## 访问

浏览器打开 <http://39.106.48.34>，弹出 BasicAuth 对话框，输入你设置的用户名/密码即可进入演示环境。

---

## 排错命令

```bash
# 查看服务状态
systemctl status liteops

# 查看最近 100 行服务日志
journalctl -u liteops -n 100

# nginx 配置语法检查
nginx -t

# 重启服务
systemctl restart liteops
```

---

## 注意事项

- 部署脚本**幂等**，重复执行不会破坏已安装的服务（会覆盖配置并重启）。
- 所有密码与 API Key 仅写入 `/etc/liteops/liteops.env`（权限 600，仅 root 可读），不会写入仓库或打印到日志。
- 服务器上 Python 优先安装 3.11；若 deadsnakes 源不可用会回退到系统自带 3.10，脚本结尾会明确提示版本差异。

## 附：给种子用户的本地分发包

如果你还需要把产品分发给其他用户在本地使用（非服务器部署），执行不带 `--server` 参数的打包：

```bat
python scripts\make_dist.py
```

生成 `dist\LiteOps_分发包.zip`（不含 `deploy/`），内容为 `app/`、`web/`、`scripts/gen_test_data.py`、`examples/`、`docs/PRD.md`、`requirements.txt`、`run.bat`、`run.sh`、`README.md`、`首次使用指南.txt`。

种子用户收到后解压、双击 `run.bat` 即可本地启动，具体操作见压缩包内的《首次使用指南.txt》。
