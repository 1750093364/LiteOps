============================================================
  轻析 LiteOps 首次使用指南
============================================================

轻析 LiteOps 是一款轻量化数据运营提效工作台，专注于 BI 之外的
临时取数、数据清洗、报告生成与知识沉淀，不做看板与可视化大屏。

------------------------------------------------------------
  1. 安装 Python 3.11
------------------------------------------------------------
- 下载地址：https://www.python.org/downloads/
- 安装时务必勾选 "Add Python to PATH"
- 安装完成后打开命令行输入 python --version，显示 3.11.x 即成功

------------------------------------------------------------
  2. 启动轻析
------------------------------------------------------------
- 解压本压缩包到任意目录
- 双击 run.bat（Windows）或执行 bash run.sh（macOS/Linux）
- 首次运行会自动创建虚拟环境并安装依赖，约 3~5 分钟
- 看到 "Starting server: http://127.0.0.1:8000" 后
- 浏览器打开 http://127.0.0.1:8000 即可使用

------------------------------------------------------------
  3. 启用 AI 功能（可选，不配置不影响其他功能）
------------------------------------------------------------
- 注册 DeepSeek：https://platform.deepseek.com
- 完成实名认证，充值 10 元即可（够用很久）
- 在 API Keys 页面创建一个 API Key（sk- 开头）
- 进入轻析「设置」页，粘贴 Key
- Base URL 填写：https://api.deepseek.com/v1
- 模型名称填写：deepseek-chat
- 点击「测试连接」确认成功后保存

AI 仅用于报告框架生成与语言精炼，Key 只存于本机数据库，
发送给 AI 的内容只含字段名与聚合数值，绝不包含原始数据行。

------------------------------------------------------------
  4. 数据与卸载
------------------------------------------------------------
- 所有数据只存放在本机 data/ 目录下（liteops.db + files/）
- 卸载：直接删除整个项目文件夹即可，无残留
- 不会上传任何数据到服务器

============================================================
  产品边界
============================================================
轻析不做：看板大屏、数仓 ETL、实时流、统计建模引擎、多人权限。
轻析做的：临时取数、数据清洗、报告框架、知识沉淀。

更多说明见 README.md 与 docs/PRD.md。
